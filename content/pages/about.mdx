# React Bangla 🇧🇩

**React Bangla** একটি ওপেন সোর্স প্রজেক্ট, যেখানে আমরা বাংলা ভাষায় সহজ করে **ফ্রন্টএন্ড, ব্যাকএন্ড এবং ফুলস্ট্যাক** ওয়েব ডেভেলপমেন্ট শেখানোর চেষ্টা করছি। শুরুটা হয়েছিল React-এর অফিসিয়াল ডকুমেন্টেশন বাংলায় অনুবাদ করে, কিন্তু এখন আমাদের লক্ষ্য আরও বড় — একজন সম্পূর্ণ ফুলস্ট্যাক ডেভেলপার হয়ে ওঠার জন্য যা যা দরকার, তার সবকিছু এক জায়গায় বাংলায় নিয়ে আসা।

> নামে "React" থাকলেও, React Bangla এখন আর শুধু React-এ সীমাবদ্ধ নয় — এখানে ফ্রন্টএন্ড থেকে ব্যাকএন্ড পর্যন্ত সম্পূর্ণ ওয়েব ডেভেলপমেন্ট স্ট্যাক নিয়ে কনটেন্ট পাবেন।

📘 **লাইভ টিউটোরিয়াল সাইট:** [react-bangla.vercel.app](https://react-bangla.vercel.app)

## ✨ React Bangla-তে কি কি পাবেন

### 🎨 ফ্রন্টএন্ড

- ✅ অফিসিয়াল React ডকুমেন্টেশন অনুসরণ করে সহজ ও প্রাঞ্জল বাংলায় ব্যাখ্যা
- ✅ Next.js, Redux Toolkit ও Context API দিয়ে স্টেট ম্যানেজমেন্ট
- ✅ Tailwind CSS v4 দিয়ে মডার্ন, রেসপন্সিভ UI ডিজাইন
- ✅ Axios দিয়ে API ইন্টিগ্রেশন — বাস্তব প্রজেক্ট উদাহরণসহ (যেমন Facebook-স্টাইল অ্যাপ "Deshi Book")

### ⚙️ ব্যাকএন্ড ও ফুলস্ট্যাক

- ✅ REST API ও json-server দিয়ে ব্যাকএন্ড কনসেপ্ট শেখা
- ✅ ফ্রন্টএন্ড-ব্যাকএন্ড ইন্টিগ্রেশনসহ সম্পূর্ণ প্রজেক্ট-ভিত্তিক টিউটোরিয়াল (যেমন "দেশি বাজার")
- ✅ ধাপে ধাপে সম্পূর্ণ অ্যাপ্লিকেশন তৈরি করা শেখা — শুধু থিওরি নয়, প্র্যাকটিক্যাল ইমপ্লিমেন্টেশন

### 📖 ক্যারিয়ার ও অতিরিক্ত রিসোর্স

- ✅ চাকরির ইন্টারভিউর জন্য বাংলায় React ইন্টারভিউ প্রশ্ন
- ✅ React শেখার জন্য বাংলা ইবুক
- ✅ প্রতিটি অধ্যায়ে উদাহরণসহ ব্যাখ্যা ও অনুশীলনী
- ✅ ওপেন সোর্স ও কমিউনিটি চালিত

## 🚀 কিভাবে শুরু করবেন

### ১. প্রজেক্ট ক্লোন করুন

```bash
git clone https://github.com/codedbyMojnu/react-bangla-tutorial.git
cd react-bangla-tutorial
```

### ২. ডিপেন্ডেন্সি ইনস্টল করুন

```bash
npm install
# অথবা
pnpm install
```

### ৩. ডেভেলপমেন্ট সার্ভার চালু করুন

```bash
npm run dev
# অথবা
pnpm dev
```

এখন আপনার ব্রাউজারে যান: [http://localhost:3000](http://localhost:3000)
